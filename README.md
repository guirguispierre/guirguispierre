### stuff i made that actually works

- **[DevinDesktopCUA](https://github.com/guirguispierre/DevinDesktopCUA)**: lets an agent drive a mac. screenshots, clicks, typing, and a little cursor so you can watch it work.
- **[sfsu-agents](https://github.com/guirguispierre/sfsu-agents)**: sfsu's class search and catalog, but agents can read it.
- **[pokedex](https://github.com/guirguispierre/pokedex)**: a discord bot that triages bugs so humans don't have to pretend they read every report.
- **[spotifyMCP](https://github.com/guirguispierre/spotifyMCP)**: your agent can queue songs now.
- **[bit-chat](https://github.com/guirguispierre/bit-chat)**: a tiny llm that runs entirely in your browser. no server, no api key, no excuses. built for the handshake codex competition and the sfsu student ai awards.
